# 📋 Система оценки номеров — Руководство по настройке

## Структура файлов

```
patterns-config.js    # Таблица паттернов (ГЛАВНЫЙ ФАЙЛ ДЛЯ ИЗМЕНЕНИЙ)
price-engine.js       # Движок расчёта (не трогать без необходимости)
index.html            # Основная игра (импортирует price-engine.js)
```

---

## 🎯 Как добавить/изменить паттерн

Откройте `patterns-config.js` и найдите массив `PATTERNS`. Каждый паттерн — это объект:

```javascript
{
    id: "unique_id",              // Уникальный ID (латиницей, без пробелов)
    name: "Название для логов",   // Не показывается игроку
    check: { ... },               // Условие срабатывания (см. ниже)
    multiplier: 10,               // Множитель цены (число ИЛИ функция)
    category: "gold",             // Редкость: diamond/gold/silver/bronze/fancy/common/lucky
    description: "Текст причины", // Показывается игроку (строка ИЛИ функция)
    exclusiveGroup: "group_name", // Опц.: только один из группы сработает
    exclusive: true,              // Опц.: если сработал — остальные игнорируются
    priority: 50                  // Приоритет (чем выше, тем раньше проверяется)
}
```

---

## 🔍 Типы проверок (`check`)

| Тип | Пример | Описание |
|-----|--------|----------|
| `regex` | `{ regex: "(\\d)\\1{3}" }` | Регулярное выражение (4 одинаковые цифры подряд) |
| `fn` | `{ fn: (num, ctx) => num.endsWith("00") }` | Функция: `num` — 10-значный номер, `ctx` — контекст (level, etc.) |
| `endsWith` | `{ endsWith: "0000" }` | Проверка окончания номера |
| `exact` | `{ exact: "REPEAT_10" }` | Спец. маркер для "все 10 цифр одинаковые" |

## 📊 Категории редкости (`category`)

| ID | Название в UI | Цвет | Базовый XP |
|----|---------------|------|------------|
| `diamond` | БРИЛЛИАНТОВЫЙ | Бирюзовый | 1000 |
| `gold` | ЗОЛОТОЙ | Золотой | 150 |
| `silver` | СЕРЕБРЯНЫЙ | Серебристый | 50 |
| `bronze` | БРОНЗОВЫЙ | Бронзовый | 25 |
| `fancy` | КРАСИВОЕ ОКОНЧАНИЕ | Обычный | 10 |
| `common` | Обычный | Обычный | 5 |
| `lucky` | УДАЧНЫЙ | Розовый | 30 |

---

## ⚙️ Флаги управления

| Флаг | Эффект |
|------|--------|
| `exclusive: true` | Если сработал — **полная остановка** проверки остальных паттернов |
| `exclusiveGroup: "name"` | В группе сработает **только первый** (по приоритету) |
| `priority: 100` | Порядок проверки (выше = раньше). Легендарные: 100, Эпические: 80-90, Обычные: 10-30 |

## 💰 Множитель (`multiplier`)

Можно задать:
- **Число**: `multiplier: 15` — фиксированный множитель
- **Функция**: `multiplier: (num, ctx) => 1 + Math.random() * 5` — динамический (для lucky)

> Функция получает `num` (10-значный номер) и `ctx` (контекст: `level`, `operatorMultiplier`, `boostMultiplier`).

---

## 📝 Описание (`description`)

Можно задать:
- **Строку**: `description: "Окончание 7777"`
- **Функцию**: `description: (num) => \`Окончание *\${num.slice(-4)} (4 одинаковые)\``

> Функция получает `num` и возвращает строку для показа игроку.

## 🎲 Примеры

### Добавить паттерн "Три семерки где угодно"
```javascript
{
    id: "three_sevens_anywhere",
    name: "Три семерки в номере",
    check: { regex: "7.*7.*7" },
    multiplier: 2,
    category: "fancy",
    description: "В номере есть три семерки",
    priority: 15
}
```

### Сделать "0000" более ценным
Найдите паттерн `end_0000` и измените:
```javascript
multiplier: 10,  // было 5
```

### Добавить бонус за уровень 100
```javascript
{
    id: "level_100_bonus",
    name: "Максимальный уровень",
    check: { fn: (num, ctx) => ctx.level >= 100 },
    multiplier: 2,
    category: "lucky",
    description: "Бонус за 100 уровень!",
    priority: 1
}
```

---

## 🔄 Группы исключения (exclusiveGroup)

Используются, когда несколько паттернов описывают одно и то же, но с разной силой.

**Пример:** Серии одинаковых цифр (`repeat_3` ... `repeat_9`) — сработает только самая длинная серия.
```javascript
exclusiveGroup: "repeat_series"
```

**Пример:** Окончания (`end_4_same`, `end_3_same`, `end_pair`) — сработает только лучшее.
```javascript
exclusiveGroup: "fancy_ending"
```

## 🧪 Тестирование изменений

```bash
node test-patterns.js
```

Создайте временный `test-patterns.js`:
```javascript
import { calculatePrice } from './price-engine.js';

const tests = [
    { num: "7777777777", desc: "10 семерок" },
    { num: "1234567777", desc: "Окончание 7777" },
    { num: "1234567890", desc: "Обычный" },
];

for (const t of tests) {
    const r = calculatePrice(t.num.padStart(10, '0'), 1, { level: 10 });
    console.log(`${t.desc}: ${r.price.toLocaleString()} ₽ [${r.category}] — ${r.reasons.join('; ')}`);
}
```

## 📦 Базовые цены генераторов

В `patterns-config.js`:
```javascript
export const BASE_PRICES = {
    1: 150,    // Рынок
    5: 1250,   // Магазин
    20: 10000  // Ювелирный
};
```

---

## ⚠️ Важные правила

1. **Не удаляйте** `exclusiveGroup` у существующих паттернов — это сломает логику
2. **Приоритеты**: Легендарные (100) → Эпические (80-90) → Обычные (10-70) → Lucky (5)
3. **Максимальная цена**: 1 000 000 000 ₽ (хардкап в движке)
4. **Минимальная цена**: базовая цена генератора (150/1250/10000)
5. После изменений в `patterns-config.js` — просто перезагрузите игру (модули ES загрузятся заново)
